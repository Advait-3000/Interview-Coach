# Feature Catalogue

| Feature | Priority | MVP rule |
|---|---|---|
| Registration/login/logout | P0 | Unique email, hashed password, role-aware routing |
| Student dashboard | P0 | Clear entry points and summary of recent activity |
| Category/difficulty selection | P0 | Only active questions appear |
| Practice mode | P0 | Immediate or end-of-question feedback, consistent with UI specification |
| Mock assessment | P0 | Stable question set for the attempt |
| Automatic scoring | P0 | One correct option, no negative marking by default |
| Attempt history | P0 | Only signed-in user's records |
| Topic-wise analysis | P0 | Show percentage and number of answers |
| Admin question management | P0 | Validated create/edit/activate/deactivate |
| Search/pagination | P1 | Useful when question bank grows |
| CSV export | P2 | Only after core features are stable |
| AI/voice/resume/company-specific features | Future | Explicitly excluded from MVP |

## Definition of a feature
Each feature needs a user flow, acceptance criteria, error states, tests, and documentation. Do not treat a screen mockup as a working feature.
