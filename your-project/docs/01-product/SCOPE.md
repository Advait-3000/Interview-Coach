# Scope

## In scope — MVP
1. Local desktop UI using JavaFX.
2. Student registration, login, logout, and role-aware navigation.
3. Question bank with categories, difficulty, answer options, explanation, and active status.
4. Practice mode.
5. Mock assessment mode with a selected set of questions.
6. Automatic scoring of multiple-choice answers.
7. Saved attempts and question-level answers.
8. History and category-wise performance.
9. Admin question CRUD and validation.
10. MySQL schema, synthetic seed data, tests, setup docs, and packaged demo.

## Out of scope — explicitly
- AI-generated questions or answer evaluation.
- Speech/voice analysis.
- Resume upload and parsing.
- Online interview rooms, video calls, proctoring.
- Third-party platform scraping or integrations.
- Mobile apps and public cloud hosting.
- Subjective HR answer grading.

## Stretch goals, only after MVP passes
- Export results to CSV.
- Search and pagination in admin question bank.
- Configurable assessment timer.
- More question formats, if scoring and schema are redesigned deliberately.

## Scope control
A feature is not added merely because it sounds useful. Record it in `DECISIONS.md`, define acceptance criteria, estimate its impact, and obtain project-owner approval before implementation.
