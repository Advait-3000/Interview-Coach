# Design System

## Direction
A calm, academic, focused desktop interface. Prioritize clarity and quick practice over decorative effects.

## Visual tokens
- Background: very light neutral (`#F6F8FB`)
- Surface: white (`#FFFFFF`)
- Primary: deep blue (`#2457C5`)
- Primary hover: darker blue (`#19449F`)
- Main text: charcoal (`#1E293B`)
- Secondary text: slate (`#64748B`)
- Success: green with text/icon, not color alone
- Warning: amber with text/icon
- Error: red with text/icon
- Border: light slate (`#DCE3ED`)

These are starting tokens, not a constraint if the team later creates a consistent alternative.

## Typography
Use system fonts initially. Screen titles 24–30 px equivalent, section titles 18–22, body 14–16, helper text no smaller than 12 where possible.

## Spacing and surfaces
Use a consistent 8 px spacing rhythm, clear grouping, restrained borders, and consistent button heights. Avoid excessive shadows and gradients.

## Components
Buttons, text fields, cards, badges, question options, progress indicators, dialogs, tables, and empty/error states must share consistent styling. See `COMPONENTS.md`.

## Interaction states
Every interactive control needs default, hover, keyboard-focus, disabled, and validation/error states where applicable.
