# Definition of Done

A task is done when:
- Requirements and acceptance criteria are met.
- Code follows architecture and naming rules.
- Relevant unit/integration/manual tests pass.
- Validation and failure paths are covered.
- No secrets or real student data are committed.
- Documentation and `PROJECT_STATUS.md` are updated.
- The application builds and the feature has been demonstrated.
- The agent reports exactly what it verified and what remains unverified.

A generated file or a plausible code snippet alone does not prove the feature works.
