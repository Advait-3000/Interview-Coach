# Bug Tracking

## Bug report template
- **ID:**
- **Title:**
- **Environment:** OS, Java version, Maven version, MySQL version
- **Steps to reproduce:**
- **Expected result:**
- **Actual result:**
- **Frequency:** always / intermittent
- **Severity:** blocker / high / medium / low
- **Evidence:** safe logs or screenshot; remove personal data and secrets
- **Related test:**
- **Status:** open / in progress / fixed / verified

## Severity guide
- Blocker: app cannot build/start or core data is corrupted.
- High: authentication, authorization, scoring, or persistence is incorrect.
- Medium: important flow has a workaround.
- Low: cosmetic issue or minor usability improvement.

Do not paste database passwords, access tokens, or real student information into bug reports.
